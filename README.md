# Phone Directory System 📱

A console-based Phone Directory System built using **C++**. This application allows users to easily manage their contacts with features to add, search, display, and delete records. Data is persistently stored in a text file.

---

## 🚀 Features
* **Add Contacts:** Add new contacts with names and phone numbers.
* **Display Contacts:**
  * View all saved contacts.
  * View contacts sorted alphabetically.
  * Search for a specific contact by name or phone number (Case-Insensitive).
* **Delete Contacts:** Delete a specific contact or clear the entire directory.
* **Data Persistence:** Automatically loads and saves contacts to `contacts.txt`.

---

## 🛠️ Tech Stack
* **Language:** C++
* **Core Concepts:** File I/O (`fstream`), Arrays, Structs, Sorting (`std::sort`), and String Manipulation.

---

## 📂 Files Included
* `Phone_Directory_System.cpp` : The main source code file.
* `contacts.txt` : The text file where contact data is stored.
